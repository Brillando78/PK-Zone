# PK-Zone 
application web de gestion de parking développée avec symfony et twing. Le projet vise à simplifier la gestion des véhicules, des emplacements et des opérations de stationnement à travers une interface claire et intuitive 

# Fonctionalités 
- gestion des vehicules 
- gestion des emplacements de parking
- suivi des entrées et sorties 
- gestion des durées de stationnement 
- suivi des paiments
- tableau de bord avec statistiques
